# Mini Claude Offline AI

مشروع بناء تطبيق محادثة محلي لأجهزة Android، مع محرك llama.cpp.

## الجهاز المستهدف
- Huawei P30 Pro / Android 10 / ARM64
- APK تجريبي من GitHub Actions
- يعمل الاستدلال محلياً بعد اختيار ملف نموذج GGUF من الهاتف.
- لا يحتاج التطبيق إلى اتصال بالإنترنت أثناء الاستدلال بعد توفير النموذج.

## إنشاء APK من الهاتف
1. افتح تبويب **Actions** في هذا المستودع.
2. اختر **Build Mini Claude APK**.
3. اضغط **Run workflow** ثم **Run workflow** مرة أخرى.
4. انتظر انتهاء البناء بنجاح.
5. افتح نتيجة التشغيل ونزّل artifact باسم **Mini-Claude-Offline-APK**.

## ملاحظة مهمة عن النموذج
ملف النموذج ليس مضمنًا داخل APK لأن حجمه كبير. بعد تثبيت التطبيق، اختر ملف GGUF من مساحة الهاتف. للحصول على أداء مناسب لذاكرة 8GB ابدأ بنموذج instruct صغير بحجم 1B–3B وكمية تكميم Q4. تنزيل النموذج يحتاج إنترنت مرة واحدة؛ المحادثة نفسها محلية بعد ذلك.

## البناء
يستخدم GitHub Actions نسخة Android الرسمية التجريبية من llama.cpp كمحرك محلي. البناء يتطلب Android SDK/NDK وCMake، ويتم إعدادها في بيئة GitHub Actions.
